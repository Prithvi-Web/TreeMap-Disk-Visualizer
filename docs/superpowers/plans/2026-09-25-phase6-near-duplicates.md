**Goal:** the near-duplicate view finds resized, re-encoded, format-converted and lightly cropped copies of a picture with precision ≥ 0.98 at the default threshold and the recall the master prompt sets (§5.5), over a 200,000-image library in ≤ 90 s on Tier B, never handing any decoder a path, never decoding more of an image than its signature needs, never opening a file whose data is not on the disk, and never letting an image vanish from the result without a counted reason — and a rescan of an unchanged library costs one metadata call and one cache row per image, never a read. Every quality figure comes from a synthetic corpus until the owner's real-library run (T16) exists, and says so (RISKS R50 stays open).

**Architecture:** a new crate `tm-imghash` does everything that touches pixels outside sharp. It probes image heads (JPEG markers, EXIF orientation and the IFD1 thumbnail, the dimensions of every listed format), decodes EXIF thumbnails with `zune-jpeg`, asks macOS ImageIO (on Apple silicon) for a thumbnail of what sharp cannot decode (HEIC's only route), turns every decode into one oriented 32×32 RGB grid, and computes the composite signature from that grid — pHash 64 (a hand-written DCT over a constant cosine table, so the bits are the same on every platform), dHash 64, 48 bits of colour moments, and the main image's displayed width and height. The same crate holds the multi-index search (four 16-bit bands on both 64-bit codes, exact verification with the tuned composite distance, union-find, every cluster split at τ around its representative) and the near-miss search Phase 7 needs. **It reads files one way only: every image is read once, on the image job's own thread, through Phase 5's `tm_hash::open_verified`, immediately after a fresh probe of that image** (metadata only: identity equal to the submitted key, still local, not a link, a regular file) — and no wait of any kind (pause, throttle, worker limit, the bytes budget) ever falls between that probe and that open. The head (≤ 1 MiB) is read first; if the EXIF thumbnail signs the image nothing more is read; otherwise the rest of the file is read from the same descriptor, `still_same()` is checked after the last byte, and **the bytes — never the path — go to Node**, where `sharp(buffer)` still shrinks on load. ImageIO reads through a `CGDataProvider` over the verified descriptor (or over bytes that descriptor already produced), never a URL. The bytes in flight are capped by a budget reserved before each probe, so they stay inside the 500 MB RSS budget. Every candidate first goes through **Phase 5's probe job**; the signature cache (a `signatures` table in Phase 5's `content-cache.db`) is looked up between that probe and the image job, so a hit costs no read. The image job runs on governed threads of its own behind a handle Node polls (P3-1). Node never opens an image for the fast tier. Where Node must read one itself — the legacy tier, the thumbnail warm and the thumbnail route, the Compare viewer — it uses one reader, `readImageVerified`: the module's one-shot verified read where the module loads, a Node fallback where it does not, whose residual is stated wherever it runs (without the module only the scan's flags decide what is local, RISKS R71's documented residual, and a parent directory swapped for a link is not caught). A threshold change re-clusters the signatures the handle already holds; nothing is probed or read again. The legacy dHash pass stays as the fallback — when the module is missing, when sharp is, and whenever the fast tier fails at runtime — with its event-loop stall and its dead cancellation fixed and its failures counted.

### The ladder, per format

The format is sniffed from the head, never taken from the extension. Every row starts the same way: the checkpoint, the fresh probe, `open_verified`, the head read.

| Format | Rung 1 (Rust) | Rung 2 (Node, sharp on the job's bytes) | Rung 3 (Rust, Apple-silicon macOS) | When every rung fails or none exists |
| --- | --- | --- | --- | --- |
| JPEG | `exifThumb`: an IFD1 JPEG (Compression 6) whose aspect matches the main image within 2%, or is letterboxed with uniform bars (cropped to its content box), and whose sides are ≤ `maxThumbSide` (640) | `shrinkOnLoad` | `platformThumb` (over the same bytes) | `decodeFailed` |
| WebP | — | `shrinkOnLoad` | `platformThumb` (over the same bytes) | `decodeFailed` |
| PNG, GIF (first frame), BMP, TIFF, AVIF, unknown | — | `full` | `platformThumb` (over the same bytes) | `decodeFailed` |
| HEIC / HEIF (HEVC) | `exifThumb`, only if T3's evidence step finds IFD1 JPEG thumbnails in HEIC's `Exif` item | — (no HEVC decoder in the shipped sharp) | `platformThumb` over the verified descriptor (the only route) | `formatNotDecodableHere` (Windows, Linux, Intel Macs, and wherever the platform rung is off), after one head read |

A distrusted EXIF thumbnail (aspect disagrees and the bars are not uniform, too large, or it fails to decode) falls to the next rung; `decodePath` then names the rung that answered. An image that needs rung 2 and is larger than `maxImageBytes` is `tooLarge` after its head read; one above sharp's pixel cap is `tooLarge`; sharp missing while the module loads sends the whole job to the legacy tier (P6-18). Every signature carries the main image's displayed size (P6-8).

pub const SIG_VERSION: u16 = 1;                  // bumped by any change to the pixels reaching a grid or the bits computed from it
pub const GRID: usize = 32;
pub const RGB_BYTES: usize = GRID * GRID * 3;    // 3,072: the only pixels any path hands on
pub const SIG_BYTES: usize = 32;

#[repr(u8)] #[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum DecodePath { ExifThumb = 1, ShrinkOnLoad = 2, Full = 3, PlatformThumb = 4 }

/// TIFF tag 0x0112; `Up` when absent.
#[repr(u8)] #[derive(Clone, Copy, PartialEq, Eq, Debug)]

/// A 32×32 RGB picture as displayed (oriented), row-major.
pub struct Grid(Box<[u8; RGB_BYTES]>);

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Signature {
    pub phash: u64,       // bit u·8+v: DCT coefficient (u, v) of the 32×32 grey > the 8×8 block's median
    pub dhash: u64,       // bit r·8+c: 9×8 grey cell (r, c+1) > cell (r, c)
    pub colour: [u8; 6],  // Y, Cb, Cr, 16 bits each, big-endian: mean 8 | std 5 | skew 3
    pub width: u32,       // the MAIN image's displayed size (after orientation) — never a thumbnail's, never the grid's; 0 = unknown
    pub height: u32,
    pub decode_path: DecodePath,
}
impl Signature {
    /// phash BE 8 ‖ dhash BE 8 ‖ colour 6 ‖ width BE 4 ‖ height BE 4 ‖ decode_path 1 ‖ 0.
    pub fn pack(&self) -> [u8; SIG_BYTES];
    pub fn unpack(bytes: &[u8]) -> Result<Signature, SigError>;   // refuses a wrong length or path byte
    /// Nearest tenth of log2(width / height), from a constant boundary table; None when a side is 0.
    pub fn aspect_bucket(&self) -> Option<i8>;
}
pub fn grid_from_rgb(rgb: &[u8], width: u32, height: u32) -> Result<Grid, SigError>; // exact area average, aspect ignored ("fill")
pub fn orient(grid: &Grid, o: Orientation) -> Grid;                                 // an exact permutation

pub fn signature(grid: &Grid, width: u32, height: u32, path: DecodePath) -> Signature;

    pub fn probe_head(head: &[u8]) -> Result<HeadProbe, HeadError>;
}

pub mod distance {
    pub struct Weights { pub phash: f64, pub dhash: f64, pub colour: f64, pub aspect: f64 }
    /// (w.phash·H(p)/64 + w.dhash·H(d)/64 + w.colour·C + w.aspect·A) / (sum of the weights), in [0, 1];
    /// a zero weight removes its term.
    pub fn composite(a: &Signature, b: &Signature, w: &Weights) -> f64;
    pub fn colour_distance(a: &[u8; 6], b: &[u8; 6]) -> f64;      // mean of 9 normalised moment differences
    pub fn aspect_distance(a: &Signature, b: &Signature) -> f64;  // |Δbucket| / 10, capped at 1; 0 when either is unknown
}

    pub struct Params {

        pub phash_radius: u8, pub dhash_radius: u8, pub bands: Bands,
        pub aspect_gate: u8,                 // max |Δaspect bucket| for a candidate; u8::MAX = off
    }
    /// size and modified_ms are the scan's own values (what the strip shows), handed over at submit. Unknowns
