TreeMap: third-party notices for gdu
====================================

TreeMap bundles gdu (https://github.com/dundee/gdu), the engine behind
its fast scans, as one program per platform. gdu's own licence (MIT)
ships beside this file as LICENSE.md. Each program also contains code
written by others, linked into it when it was built: the Go modules
below, at the versions the program records, and the Go standard library.

Each module is listed with every licence file its source carries at that
version, word for word, leaving out only the testdata and other folders
Go never compiles. The source is the zip proxy.golang.org serves,
checked against the go.sum hash gdu records for it. "Licence" names the
licences those files grant, joined by AND.

  win-x64/gdu.exe  sha256 5766edcf981906c68e7f940c2aa9410e8d0f1e2bfd4780b892ee51077e1159bb

This file is written by scripts/gdu-notices.js from the Go build
information in those binaries, and sealed by its last line; the module
list it was written from is build/gdu/gdu-modules.json. Do not edit
either by hand: tests/gduNotices.test.ts fails when they no longer match
each other, the gdu scripts/fetchGdu.js pins, the generator or the seal.
