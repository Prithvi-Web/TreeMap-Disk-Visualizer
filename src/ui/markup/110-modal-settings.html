Scheduled scans
TreeMap re-scans these folders on a schedule while the app is running, and alerts you when a folder grows past your threshold since the previous scan. Every run is also saved to Trends. A scan that came due while TreeMap was closed runs about 10 minutes after it opens, not the moment it opens.
Scanning budget
How much of this computer a scan is allowed to use. Picking one saves it straight away.
Scan engine
Which engine reads the disk. Picking one saves it straight away and applies from the next scan. The native engine and the built-in walker count the same files the same way; gdu shows a folder it may not open as empty.
Drives mounted inside a folder
A disk image or drive mounted inside the folder you scan is a separate disk. Staying on this drive keeps the totals true to the disk you chose. Picking one saves it straight away.

Undo Vault
Everything Autopilot or the Clean Up cart moves to the Trash is copied here first and checked — so you can undo it even after emptying the Trash, until the copy expires or is dropped to make room (the two settings below). Files you move to the Trash any other way (right-click, the Grid, Duplicates, Clean Up) go to the Trash only and aren't copied.

Reclaim Score
TreeMap ranks files by how safe and worthwhile they are to delete, out of 100. These sliders decide how much each signal counts. Set one to zero to leave it out of the score entirely — that is different from it scoring zero, and a signal TreeMap simply could not read is left out too rather than counted against the file.
Clean Up target
Set how much you are trying to free and the Clean Up cart shows a meter filling toward it. Leave it empty for no target — the meter then doesn't appear at all. It only measures what you have staged; nothing is ever deleted to reach it.
Human-scale sizes
Next to sizes over about 1 GB, also say what that amounts to — "≈ 3,100 photos like the ones in this folder". The comparison always comes from the folder's own photos, videos or music (at least ten of a kind), never from a made-up average; folders with nothing comparable show nothing.
Ask in plain words
The ✨ button beside the treemap's highlight box turns plain words into a search — "big videos I haven't opened in a year" becomes size>1gb ext:mp4,… used>1y. The translation is always shown for you to check and edit before it runs, and the built-in phrase table works entirely offline — nothing here ever touches the network.
Welcome tour
Three quick wins, staged only when you click, nothing deleted.
Cloud accounts
Scan your own Google Drive, Dropbox or OneDrive in the same treemap — metadata only, no file contents are ever downloaded, and sign-in tokens never leave this computer. Bring your own (free) API app: create one in the provider's developer console with redirect URI http://127.0.0.1:53682/oauth/callback, then paste its client ID below.
Ignore list
Folders, files or patterns to leave alone. Don't scan skips them entirely; Don't suggest keeps them out of Smart suggestions only. While any pattern is set to Don't scan or Both, every scan uses the built-in walker, which is slower than the native engine. Patterns: a full path, a name like node_modules, or globs like *.iso and ~/projects/**/dist.
How TreeMap measures space
TreeMap's map and totals count the size each file claims. Where this computer can measure it, this panel shows the space the files actually take up on disk next to that, for the folder you last scanned.
Sizes are in decimal units, as Finder and drive makers count them: 1 KB is 1,000 bytes, 1 MB is 1,000,000 bytes and 1 GB is 1,000,000,000 bytes — the same units the search box reads in size>1gb. Windows Explorer divides by 1,024 instead, so it shows the same files smaller — by about 7% at gigabyte sizes.
